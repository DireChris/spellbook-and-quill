# Security Policy

## Supported Versions

Security updates are provided for the latest version available on the `main` branch or the most recent tagged release.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < Main  | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security flaw:

1. **Do not** create a public issue on GitHub.
2. Please submit a private report via GitHub's **Security > Report a vulnerability** tab, or reach out directly to the repository maintainer.
3. Provide as much details as possible to reproduce the issue.

### Response Commitment
* **Response Time:** Acknowledgment within **72 hours**.
* **Fix & Disclosure:** Validated bugs will be prioritized and fixed in an upcoming patch release.

Thank you for helping keep this project secure!
